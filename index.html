ESP32 Starter Kit

Your journey into electronics & coding starts here!

✅ What You Need

📦 Your ESP32 Kit  |  🔌 Micro-USB Cable  |  🌐 Google Chrome Browser  |  💻 Chromebook works perfectly!

🚀 How To Get Started

1

Plug It In

Connect your ESP32 board to your Chromebook using the Micro-USB cable included in your kit.

2

Pick a Project

Choose one of the projects below. Start with "Blink" - it's the classic first project for everyone!

3

Click Install

Hit the Install button, select your ESP32 from the popup, and the code uploads automatically!

4

Watch & Learn

See your project come to life! Read the explanation to understand how it works.

🛠️ Projects

Flash pre-built firmware directly from your browser — no software needed!

Project 1: Blink

⭐ Beginner

The classic "Hello World" of electronics! Make the built-in LED on your ESP32 blink on and off. You'll learn about digital outputs and how code controls hardware.

ESP32 Board Built-in LED

Project 2: Traffic Light

⭐ Beginner

Build a mini traffic light using red, yellow, and green LEDs! Learn about resistors, breadboard wiring, and controlling multiple outputs.

ESP32 Red LED Yellow LED Green LED Resistors Breadboard
⚠️ Use Chrome Browser
🌡️

Project 3: Weather Station

⭐ Beginner

Read real temperature and humidity from the DHT11 sensor and display it on the OLED screen. Your own mini weather station!

ESP32 DHT11 Sensor OLED Display Jumper Wires
⚠️ Use Chrome Browser
🚨

Project 4: Motion Alarm

⭐⭐ Intermediate

Use the PIR sensor to detect motion and trigger an LED alarm! Learn about digital inputs and how sensors communicate with microcontrollers.

ESP32 PIR Sensor Red LED Breadboard
⚠️ Use Chrome Browser

Project 5: Light Meter

⭐⭐ Intermediate

The photosensitive resistor detects light levels and displays them on the OLED. Learn about analog inputs and how to read sensor data!

Project 6: Smart Dashboard

⭐⭐⭐ Advanced
